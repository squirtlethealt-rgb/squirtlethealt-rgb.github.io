HOW IT WORKS: on-device face-mesh tracking follows the cheek/nose/chin marks shown as tracking dots. The suit's helmet region is auto-detected from the 3D model on load and used as the anchor point — so the helmet locks to your head/face while the rest of the suit hangs below it at the correct proportion. Sizing then keeps rescaling live off the tracked distance between your cheeks, just like the face width calibrates a mask — closer, farther, or a different face will re-fit automatically when "auto re-fit" is on.

FRAMING TIP: since this is a full body suit anchored from your face, step back from the camera so your torso is in frame too, not just your face — otherwise the suit will appear zoomed in. Use Size × and Height in Fine-tune to nudge the fit once you can see yourself. If the suit appears to be facing backward, tick "flip suit 180°" above.

EMBEDDING ON WIX: (1) The suit model link is already set to your Wix Media file (Advanced_Crew_Escape_Suit.glb) in SUIT_URL near the top of the <script> below — replace it if you re-upload. (2) In Wix, add this via an "Embed Code → Embed a Widget / HTML iframe" element and paste this whole file's contents in, or upload it as a custom-code file. (3) Open that element's settings and make sure camera permission is allowed for the embed (Wix's embed panel has a permissions toggle for camera/mic — turn it on, otherwise the browser silently blocks the camera inside the iframe). (4) Camera access only works on the published site or Preview mode over HTTPS, not inside the Wix editor canvas. (5) Set the element's height so the widget isn't cropped — it's responsive and will size itself to the width you give it.
