HOW SIZING WORKS: on-device face-mesh tracking follows the cheek/nose/chin marks shown as green dots. The mask calibrates a baseline fit against those marks the moment a face is seen (about half a second), then keeps rescaling live off the real tracked distance between the marks every frame — closer, farther, or a visibly different face size will re-fit automatically when "auto re-fit" is on above. You can still force an instant re-fit with the "Recalibrate" button. Toggle "show tracking marks" to see the live landmark points sizing is based on.

EMBEDDING ON WIX: (1) Upload oni_no_face_mask.glb to your Wix Media/File manager, copy its public HTTPS link, and paste it into MASK_URL near the top of the <script> below. (2) In Wix, add this via an "Embed Code → Embed a Widget / HTML iframe" element and paste this whole file's contents in, or upload it as a custom-code file. (3) Open that element's settings and make sure camera permission is allowed for the embed (Wix's embed panel has a permissions toggle for camera/mic — turn it on, otherwise the browser silently blocks the camera inside the iframe). (4) Camera access only works on the published site or Preview mode over HTTPS, not inside the Wix editor canvas. (5) Set the element's height so the widget isn't cropped — it's responsive and will size itself to the width you give it.
