PROOF OF CONCEPT — tracks the face in 3D (position, rotation, depth) using on-device face mesh tracking, then renders the uploaded mask model locked to the head. It calibrates a baseline fit over the first second a face is seen, then keeps scaling live off the actual tracked marks after that — if the face gets closer, farther, or a different person puts it on, the mask resizes to match, smoothed so it doesn't flicker frame to frame. Hit "Recalibrate mask size" to reset the baseline at any point. Toggle "show tracking marks" to see the live landmark points the mask's size and position are following. If tracking can't load (slow network, unsupported browser), the mask still renders and can be positioned by dragging.

IMPORTANT: don't open this file by double-clicking it — browsers block a local HTML file from loading the .glb next to it that way. Instead, from the folder containing both files, run a tiny local server and open the printed address, e.g.: python3 -m http.server 8000 then visit http://localhost:8000/lens-demo-3d.html. (Once this is embedded on Wix itself, this issue goes away — Wix serves everything over normal HTTPS.)
