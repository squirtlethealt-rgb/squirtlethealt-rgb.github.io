# Python Classroom LMS & In-Browser IDE

Certificate Course in Python Programming (Sessions 1–4, Milestone 1).

🚀 Hosted on GitHub Pages: [https://squirtlethealt-rgb.github.io/](https://squirtlethealt-rgb.github.io/)

## Applications Included
- **Python Course Portal (`index.html`)**: Interactive student dashboard, milestones, mission badges, session curriculum, and practice challenges.
- **Python Classroom IDE (`ide.html`)**: In-browser Python coding environment with:
  - Blank editor start & guided lesson examples (Sessions 1–4)
  - Interactive In-Console terminal inputs with no popup interruptions
  - In-browser virtual filesystem with `json` and `os` support
  - Pyodide 3.11 WASM execution engine fallback
  - Student local workspace saving, file downloads (.py, .zip), and direct file saving
